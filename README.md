## Featured Project

### Supply Chain Supplier Compliance & Performance Analytics

The main portfolio project in this repository applies SQL, Python and Power BI to a realistic supplier-management scenario.

It transforms supplier, order and compliance data into management-ready KPIs, supplier risk classifications, performance scores, rankings and an interactive Power BI dashboard.

**Technologies:**

- SQL
- SQLite
- Python
- Pandas
- Power BI
- Git & GitHub
